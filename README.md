## CSCE 30503 Operating Systems: Shell Assignment Version One

### Learning Objectives:
1. Understand the fundamentals of process creation, management, and execution in Linux.
2. Gain proficiency in using system calls and functions for implementing shell functionalities, including executing internal and external commands, handling command-line arguments, implementing file redirection, and managing command pipelines.
3. Learn about signal handling mechanisms in Linux, particularly for handling SIGINT signals.
4. Develop problem-solving skills through designing and implementing a robust and responsive shell program.

### Assignment Description:
Your task is to develop a **shell program** in Linux that replicates the basic functionalities of a command-line shell, including the ability to execute internal and external commands, handle command-line arguments, and handle SIGINT signals (Interrupts).

### Instructions:
1. **Basic Shell Functionality**:
   - Implement a basic shell interface that continuously reads input from the user.
   - Parse the input to identify commands and arguments. Command line arguments will need to be formatted into *NULL terminated Char Pointer Array (*char args[])*
   - Implement a ability to execute internal commands, **exit** and **cd** with command-line arguments.
   - Implement a ability to execute external commands with command-line arguments.

2. **Signal Handling for SIGINT**:
   - Implement signal handling to catch and handle **SIGINT** signals (generated by pressing Ctrl+C).
   - Upon receiving a SIGINT signal, ensure that the currently executing command is interrupted gracefully.
   - Allow the user to continue interacting with the shell after a SIGINT signal without terminating the shell.

### System Calls and Functions

This is listing of the most common system calls and commands that will be used to complete the assignment. This is not an exhaustive list.

1. `fork()`: Create a new process for executing commands.
2. `execvp()`: Execute external commands in the child process.
3. `waitpid()`: Wait for the child process to complete execution.
4. `signal()`, `sigaction()`: Register signal handlers for SIGINT signal handling.
5. `kill()`: Send signals to processes, used for sending SIGINT signals to child processes.
